## 🚀 Featured Projects

### 🤖 ai-bid 智能标书合规审核系统

> Multi-Agent based intelligent bid compliance review system

一个基于 Multi-Agent 架构的智能标书合规审核平台，支持 PDF 文档解析、法规知识检索、多 Agent 协同审核以及结构化报告生成。

**技术栈：**

`Rust` `Tokio` `Axum` `ReAct` `LangChain4j` `Milvus` `SSE`

主要贡献：

- 参与设计并实现 11 个专业审查 Agent，覆盖事实核查、流程合规、合同审查、风险识别等场景。
- 实现 Coordinator Agent 调度流程，支持任务路由、并行执行、结果聚合。
- 构建 RAG 知识检索链路，实现文档解析、向量化及 Milvus 检索。
- 设计共享状态管理机制，解决多 Agent 协作过程中的上下文同步问题。

🔗 Repository:
https://github.com/dgut-hsd/ai-bid
